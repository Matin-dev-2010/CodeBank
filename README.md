# CodeBank

**CodeBank** is a C# Windows Forms desktop application for managing structured data through a simple tab-based interface.

## Overview

CodeBank is a practical desktop application built with **C#**, **Windows Forms**, **SQLite**, and **Entity Framework 6**. The project focuses on building a maintainable CRUD-oriented application with reusable form logic and database integration.

## Tech Stack

| Technology | Usage |
|---|---|
| C# | Application development |
| Windows Forms | Desktop UI |
| .NET Framework 4.6.1 | Target framework |
| SQLite | Local database |
| Entity Framework 6 | Data access / ORM |
| System.Data.SQLite | SQLite provider |

## Features & Architecture

- Tab-based Windows Forms interface
- Local SQLite database integration
- Entity Framework 6 data access
- CRUD-oriented data management
- Reusable methods for shared tab/form behavior
- Form state and data-entry management
- Handling of unsaved changes before clearing or replacing data
- Visual Studio solution/project structure

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Matin-dev-2010/CodeBank.git
```

2. Open `CodeBank.sln` in Visual Studio.
3. Restore NuGet packages if required.
4. Build the solution.
5. Run the application.
